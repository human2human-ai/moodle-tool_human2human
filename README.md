# Human2Human

Human2Human adds guided conversation activities to your Moodle courses.

**Getting started is free.** Connecting your site and running activities on the
Human2Human free plan needs no payment and no payment details.

> This plugin is in early development (alpha). It is not ready for production
> sites yet.

## What it does

Human2Human activities run in your courses through Moodle's built-in External
tool (LTI 1.3), so launches, grades and the course roster use Moodle's own
features. This admin tool connects your site to Human2Human and sets the tool
up for your teachers.

## Requirements

- Moodle 4.5 to 5.3.
- The External tool activity (`mod_lti`), which is part of standard Moodle.
- A Human2Human account. The free plan is enough to connect and use the plugin.

## Installation

1. Go to **Site administration > Plugins > Install plugins**.
2. Upload the ZIP file and install it.
3. Go to **Site administration > Plugins > Admin tools > Human2Human**.

## External service

This plugin connects your site to Human2Human, a hosted service. The data
Moodle sends at each activity launch is declared by the External tool's own
privacy provider.
